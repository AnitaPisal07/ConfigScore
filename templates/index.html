How ConfigScore Works

A simple four-step process to audit website headers, TLS certificates, and security configurations.

1

Passive Scan

Sends standard HTTP requests to inspect response headers, HTTPS redirects, TLS certificates, and DNS records safely.

2

Detect Weaknesses

Evaluates 20 common security controls against security guidelines (OWASP, RFCs) and calculates a score from 0 to 100.

3

Clear Explanations

Every finding includes a simple explanation of what was checked, why it matters, and what attack risk it prevents.

4

Fix Guidance

Provides practical code snippets for Nginx, Apache, Flask, and Express to fix missing security headers easily.
