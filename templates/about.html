About ConfigScore

A Computer Science on Web Application Security Configuration Auditing.

Objective

Web application security issues often occur not from complex application zero-day flaws, but from basic server misconfigurations — such as missing security headers (CSP, HSTS, X-Frame-Options), insecure cookie flags, or unencrypted HTTP fallbacks.

ConfigScore was developed to demonstrate passive, non-intrusive security auditing. It queries public target domains like a web browser, evaluates 20 critical configuration controls, calculates a clear risk score, and provides practical code snippets for developers to fix missing security controls.

What ConfigScore Does

  • Passive Auditing: Inspects HTTP response headers safely without running intrusive attack payloads.
  • TLS & Certificate Check: Evaluates SSL/TLS versions (TLS 1.2/1.3), certificate validity, and expiration horizons.
  • Cookie Security Verification: Audits session cookies for Secure, HttpOnly, and SameSite flags.
  • Redirect Chain Tracing: Evaluates plaintext HTTP to HTTPS redirect paths.
  • DNS CAA Resolution: Queries DNS CAA records to verify authorized Certificate Authorities.
  • Remediation Directives: Provides ready-to-use configuration directives for Nginx, Apache, Flask, and Express.

Limitations

  • No Exploitation: ConfigScore does not perform SQL injection, XSS payload testing, or brute-force attacks.
  • Public Landing Page Scope: Automated checks audit public endpoints. Internal authentication systems require manual review.
  • No Dynamic DOM Execution: Checks raw HTTP/TLS network responses; client-side JavaScript DOM rendering is not executed.
  • Review Status: When a check cannot be verified remotely (e.g. no cookies set on landing page), it is marked as "Review Required".

Technologies Used

Backend Python 3 & Flask

Handles web routing, request handling, and server-side template rendering.

Scanner Engine Requests, SSL & Socket

Performs passive HTTP client calls, socket TLS handshake probing, and dnspython CAA queries.

PDF Generator ReportLab

Generates formatted PDF audit report documents programmatically.

Frontend HTML5, Custom CSS3 & JavaScript

Clean responsive interface with accessible styling and interactive tab filtering.

Ethical & Legal Notice

ConfigScore is developed strictly for educational research and authorized defensive security checks.

Only scan web applications that you own or have explicit permission to test. Passive configuration auditing should be used as a helpful baseline check alongside proper software development practices.
