About ConfigScore

A lightweight, non-intrusive website security scanner built to help developers audit, benchmark, and harden their web applications.

Our Mission & Approach

Most web compromises do not begin with exotic zero-day exploits. Instead, they frequently stem from basic security misconfigurations: missing security headers, unencrypted plaintext fallbacks, cookies without security attributes, and legacy TLS protocol support.

While commercial security scanners exist, many are closed-source, expensive, or provide cryptic error messages without clearly explaining why a configuration matters or how to fix it. ConfigScore was created to bridge this gap by providing an open, transparent, and developer-friendly auditing platform with actionable, copy-paste fixes.

What ConfigScore Does

  • Passive Configuration Auditing: Safely queries target endpoints like a browser to record and evaluate response headers.
  • TLS & Certificate Inspection: Probes handshake protocols (TLS 1.2/1.3), cipher suites, certificate validity, and expiration horizons.
  • Cookie Security Verification: Checks session cookies for Secure, HttpOnly, and SameSite protection flags.
  • Redirect Chain Tracing: Evaluates whether plaintext HTTP gracefully transitions to HTTPS without unencrypted downgrade hops.
  • DNS Governance Check: Resolves CAA records to verify Certificate Authority authorization policies.
  • Remediation Generation: Provides concrete configuration directives for Nginx, Apache, Flask, and Express.

Important Limitations

  • Not a Penetration Test: ConfigScore does not attempt SQL injection, brute-force logins, remote code execution, or fuzzing.
  • Landing Page Scope: Automated checks evaluate the initial public landing page. Deeply authenticated pages and internal microservices require manual assessment.
  • No DOM Dynamic Rendering: Checks are performed over raw HTTP/TLS streams; complex single-page apps (SPAs) that generate DOM elements via clientside JavaScript may need browser DevTools verification.
  • Review Status: When a check cannot be reliably determined remotely (such as no cookies set on a public landing page), ConfigScore marks it as "Review Required" rather than fabricating a result.

Technology Architecture

Backend Python 3 & Flask

Lightweight WSGI framework managing routing, session management, and template rendering.

Scanning Engine Python Requests & SSL/Socket

Safe passive HTTP client, socket-level TLS SNI probing, and dnspython for CAA resolution.

PDF Generator ReportLab Platypus

Programmatic document template engine generating structured, downloadable audit reports.

Frontend HTML5, Modern CSS3 & Vanilla JS

Custom dark-themed cybersecurity interface with responsive layouts and accessible contrast.
